# v0.4.1

The environment editor now shows when a request's output overrides one of its variables.

## New Features

### Environment editor
- A variable whose name a saved request also provides as an output (see "Tokens from another request" in v0.4.0) is marked with that request's name. Requests use the value that request fetches, not the one in the environment. The mark updates as you type the variable's name.
- If that request's outputs are turned off, the mark is a warning. A request that uses the name stops with an error instead of falling back to the environment value; this is how v0.4.0 already behaved, and the editor now shows it.
- Inherited variables carry the same mark, with the full explanation when you hover over it.

## Upgrading from v0.4.0
- Nothing in your data changes.

## Platform Notes
- Restiprocity still runs on Electron 39.8.10, the last release of a line that is past its end of support. Its open advisories are fixed only in later Electron versions; moving to one is planned.
- The Windows installer is unsigned, and in-app updates are Windows-only. macOS and Linux releases remain manual downloads.
