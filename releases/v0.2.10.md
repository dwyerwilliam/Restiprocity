# v0.2.10

## New Features

### Full-Name Tooltip on Truncated Sidebar Names
- Request and group names in the sidebar that are visually truncated now show their full name as a tooltip on hover, so you can read the complete name without renaming or expanding the tree.

### Collapsed JSON Node Child Count
- Collapsed array and object nodes in the response JSON tree now display their child count (e.g. `[ … 3 ]` or `{ … 2 }`), so you can see how many entries a collapsed node holds before expanding it.

## Platform Notes
- In-app updates are supported on Windows only; macOS and Linux releases remain manual downloads.
- Windows installers are currently unsigned, so SmartScreen may show **Unknown publisher** and updates may request UAC elevation.
