# v0.2.6

## Fixes

### Query Parameter "Add" Menu Clipping
- The Params tab's **+ Add** dropdown (add empty row / import from URL) now opens right-aligned instead of left-aligned, so it stays fully inside the request editor pane instead of overflowing past the panel boundary and appearing hidden behind the response viewer.

## Platform Notes
- In-app updates are supported on Windows only; macOS and Linux releases remain manual downloads.
- Windows installers are currently unsigned, so SmartScreen may show **Unknown publisher** and updates may request UAC elevation.
- Cancelling UAC leaves the current version installed; relaunch the app and check again.
