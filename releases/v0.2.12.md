# v0.2.12

## New Features

### Full-Height Body Editor
- The request body editor now fills the entire remaining vertical space of the middle frame instead of a fixed height, with scrolling handled inside the editor.

## Fixes
- Restored JSON syntax highlighting in the request body editor. The highlighting plugin was silently crashing at runtime in packaged builds due to duplicate `@lezer/common` module copies in the bundle; the dependency layout is deduplicated and the Vite config now forces single copies of `@lezer/common`, `@lezer/highlight`, and `@lezer/lr` to prevent regression. An end-to-end test now asserts the editor renders highlighted tokens.

## Platform Notes
- Windows in-app updates continue to use the packaged updater contract (installer + blockmap + `latest.yml`); macOS and Linux releases remain manual downloads.
