# v0.2.0

## Features

### Collection Folders
- Create folders from the New control and distinguish them clearly in the sidebar.
- Move requests into folders with drag and drop, with persistence through the Electron IPC boundary.
- Handle persisted requests without a `type` discriminator when selecting and hydrating the request editor.

### Browser Regression Coverage
- Align fresh-browser `window.api` fixtures with the preload contract and cover creating and sending a request through the UI.
