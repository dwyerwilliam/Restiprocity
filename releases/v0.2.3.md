# v0.2.3

## New Features

### Windows Auto-Updates
- Add automatic update checks and background downloads for packaged Windows NSIS builds.
- Show update availability, download progress, download failures, and restart-to-apply status in the app.
- Keep installation user-triggered so updates are applied only after choosing **Restart to update**.
- Publish deterministic Windows installer, blockmap, and `latest.yml` assets through the GitHub Releases channel.
- Add a disposable GitHub Actions workflow for validating Windows N-to-N+1 updates on the `updater-test` prerelease channel.

## Platform Notes
- In-app updates are supported on Windows only; macOS and Linux releases remain manual downloads.
- Windows installers are currently unsigned, so SmartScreen may show **Unknown publisher** and updates may request UAC elevation.
- Cancelling UAC leaves the current version installed; relaunch the app and check again.
