# v0.2.16

## Fixes
- Requests created inside a folder no longer lose their name when you first set the URL. Renaming any request (root or folder level) now survives the request editor's next save; the earlier fix only worked at the root because it relied on a type marker that persisted requests never carry.

## Platform Notes
- Windows in-app updates continue to use the packaged updater contract (installer + blockmap + `latest.yml`); macOS and Linux releases remain manual downloads.
