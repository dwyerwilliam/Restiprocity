# v0.2.9

## New Features

### Create Requests Inside Folders
- New requests now respect the folder context. Select a folder and use **New Request**, or hover a folder in the sidebar and use its **+** button, to create the request directly inside that folder.
- A newly created request starts in inline-rename mode so you can name it immediately, and the folder (and any collapsed ancestors) expand to keep the new request in view.

## Documentation
- Corrected feature-status claims in the README, AGENTS.md, and functional spec (OAuth2 grant support, multipart file upload, request/response scripts, and import formats) to match what is actually implemented today.
- Documented the current CI/release pipeline, build targets, and Windows-only updater behavior.

## Platform Notes
- In-app updates are supported on Windows only; macOS and Linux releases remain manual downloads.
- Windows installers are currently unsigned, so SmartScreen may show **Unknown publisher** and a per-machine update may request UAC elevation.
