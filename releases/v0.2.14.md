# v0.2.14

## Fixes
- Renaming a request — especially a freshly created one — no longer snaps back to its previous name. The rename now stays committed even when you immediately edit the URL or other request fields, and the persisted collection file keeps the new name.

## Platform Notes
- Windows in-app updates continue to use the packaged updater contract (installer + blockmap + `latest.yml`); macOS and Linux releases remain manual downloads.
