# v0.2.11

## New Features

### JSON Request Editor
- JSON request bodies now use a CodeMirror editor instead of the previous plain text editor, with JSON syntax highlighting and inline validation diagnostics for malformed JSON.

## Platform Notes
- The supported Node.js baseline is 24.19.0. Native `better-sqlite3` handling now separates Electron and Node ABIs, with explicit rebuild paths and strict Node-ABI engine coverage.
- Each platform build runs a native Electron startup smoke test with real IPC before packaging; macOS and Linux releases remain manual downloads, while Windows in-app updates remain supported.
