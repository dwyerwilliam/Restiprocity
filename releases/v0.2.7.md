# v0.2.7

## New Features

### Larger JSON Preview Limit
- The response preview capture window (used for the JSON pretty-print tree, source text preview, and inline image preview) is raised from 1 MB to 5 MB, matching the existing text-staging budget. JSON responses up to 5 MB can now render as an interactive tree instead of silently falling back to raw text.

### JSON Tree Fallback Reason
- When a JSON response can't be rendered as a pretty-print tree, the response viewer now shows a specific reason instead of staying silent or showing a generic truncation notice:
  - Response exceeds the 5 MB preview limit
  - Response isn't valid JSON
  - JSON exceeds the 5,000-node or 64-level nesting preview budget

## Platform Notes
- In-app updates are supported on Windows only; macOS and Linux releases remain manual downloads.
- Windows installers are currently unsigned, so SmartScreen may show **Unknown publisher** and updates may request UAC elevation.
- Cancelling UAC leaves the current version installed; relaunch the app and check again.
