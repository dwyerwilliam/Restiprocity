# v0.1.12

## What's New

### Request In-Flight Overlay
- Full-screen overlay appears in the response area while a request is running
- Rising timer with tenths-of-a-second precision (`0.0s`, `1.2s`, `5.7s`, ...)
- Three-phase indicator: "Preparing request…" → "Request sent ✓" → "Waiting for response…"
- Spinning ring indicator with backdrop blur for visual clarity
- Send button stays disabled with "Sending..." text until the request completes
- Overlay works whether or not a previous response is still displayed

### cURL Import
- Paste any cURL command into the clipboard and create a new request from it
- Automatically parses method, URL, headers, body, and query parameters
- New request appears selected and ready to send

### URL Query Parameter Extraction
- Query parameters in the URL bar are now highlighted with extraction buttons
- Click the `+` button to move a parameter from the URL to the Params tab
- Extracted parameters are enabled by default and appear in the URL preview
- Moving all parameters clears the query string from the URL
- Hash fragments are preserved during extraction

### Environment Tree Viewer
- Visual tree browser for environments with parent-child hierarchy
- Navigate and select environments directly from the tree
- Inline environment deletion without closing the editor
- Variable interpolation highlighting in request fields

### Collapsible JSON Response Viewer
- JSON response viewer now supports collapsing and expanding nested objects and arrays
- Toggle buttons appear next to expandable nodes
- Empty arrays and objects no longer show a misleading collapse chevron

## Bug Fixes & Improvements

### Security & TLS
- Unsafe certificate retry is now truly one-shot — `allowInsecureCertificates` no longer persists after a "Send anyway" retry
- TLS bypass is scoped to a partitioned session for insecure requests, preventing credential leakage
- Clipboard IPC narrowed to cURL import only, reducing attack surface

### Query Parameters & URL Handling
- Improved query parameter decoding — special characters and `+` signs are now properly decoded
- URL overlay hash ordering fixed — hash fragments are now preserved correctly
- URL preview correctly shows extracted query parameters

### Code Quality
- Replaced `as any` casts with properly typed `window.api` mocks in tests
- Type-safe request store with explicit `requestStartTime` and `requestPhase` fields
- Cleaner separation between in-flight state and response state

## Under the Hood
- CI artifacts directory renamed from `release/` to `releases/artifacts/` for clarity
- Release notes file support added to CI pipeline — each tag must have a matching `releases/vX.Y.Z.md`
