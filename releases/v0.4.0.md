# v0.4.0

Requests can now take their token from a login request's response.

## New Features

### Tokens from another request
- A login or token request can provide values from its response on its new **Outputs** tab: a JSON field (a JSON Pointer such as `/access_token`), a response header, or the whole body. Any other request uses them as `{{api_token}}`: as its Bearer token, in a header, the URL or the body.
- A request that needs a value runs the saved token request first when there is no fresh value for the selected environment, then sends itself with it. Later requests reuse the value until the refresh time (default 3600 seconds), or sooner when the response's `expires_in` is shorter. Nothing runs on a timer, so an idle app sends nothing.
- If a GET, HEAD or OPTIONS request sent with a cached value gets HTTP 401, a new value is fetched and the request is sent once more. Other methods return their 401 unless you choose to resend any method, so a POST body is never sent twice unasked.
- **Refresh now** fetches new values on demand and can be cancelled. **Clear cached values** forgets them. The tab shows when the values were fetched and when they refresh.
- Values are kept in memory only, separately for each environment, and a restart starts empty. The response body of a request that provides outputs is not saved to history or to the request file.
- If the token request fails, returns an error status, or the field is missing, the request is not sent, and the error names the token request and the field. Nothing falls back to an older token.
- A request that uses an output follows redirects only within the same origin, and never from HTTPS to HTTP.
- **Copy as cURL** includes a fresh cached value after the usual confirmation, and never runs the token request.
- Insomnia `{% response %}` tags that read a request in the same export become outputs of that request.
- An output name can be provided by one request only, and a token request can't use another request's outputs.

## Fixes
- Saving a response (Save As, or a download) no longer offers a file name that would run, install or mount when opened, such as `report.pdf.exe`: a harmless extension is added, and you can still type any name. On Windows and macOS the saved file is marked as downloaded from the internet, so the system warns before opening it.
- An encrypted Secret is now tied to its environment and variable. A value copied to another variable or environment in the files is refused on reveal and on send, before anything is sent. A send that stops on an unreadable Secret says why.
- The app no longer downloads spellcheck dictionaries from Google's servers on its own. This happened mostly on Linux, and on Windows in languages it has no dictionary for. Spellchecking is now off in every field, since they hold URLs, tokens and JSON.

## Under the Hood
- js-yaml, undici and fast-uri are updated for published security advisories.
- Release builds pin their GitHub Actions to exact commits, give the workflow write access only to publish, and fail on a high-severity advisory in a shipped dependency. Each release includes `SHA256SUMS.txt` and a build provenance attestation for its files.

## Upgrading from v0.3.1
- Your collections, folders, environments and settings load as they are.
- Secrets saved by v0.3.1 are tied to their variable at the first start when they can be decrypted. One that can't be decrypted is kept as it is.
- The history database gains a column at the first start. v0.3.1 ignores it.
- Before installing an older version again, back up the `environments` folder in your data folder. v0.3.1 reports Secrets saved by v0.4.0 as unreadable (it keeps them but can't use them), and it ignores request outputs, so `{{api_token}}` would be sent as written.

## Platform Notes
- Restiprocity still runs on Electron 39.8.10, the last release of a line that is past its end of support. Its open advisories are fixed only in later Electron versions; moving to one is planned.
- The Windows installer is unsigned, and in-app updates are Windows-only. macOS and Linux releases remain manual downloads.
